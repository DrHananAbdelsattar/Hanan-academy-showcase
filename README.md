# Hanan Academy — Website Showcase

A bilingual (Arabic / English) showcase of the **Hanan Academy** website: courses,
lessons, articles, FAQ, certificate verification and a student dashboard mock-up.
Designed and developed by Dr. Hanan Abdelsattar.

نسخة عرض ثنائية اللغة (عربي / إنجليزي) لموقع **أكاديمية حنان**، تشمل الدورات
والدروس والمقالات والأسئلة الشائعة وصفحة التحقق من الشهادات ونموذجًا للوحة الطالب.
من تصميم وتطوير د. حنان عبدالستار.

**Live demo:** https://drhananabdelsattar.github.io/Hanan-academy-showcase/

Start from the language gateway, `index.html`.

## Demo version — please read first

This is a **viewing-only demo**. The sign-in and sign-up forms are not connected
to a server, so please do not enter real data. No payments are processed here and
no real student records are stored.

هذه **نسخة تجريبية للعرض فقط**. نماذج تسجيل الدخول وإنشاء الحساب غير مرتبطة بخادم،
فلا تُدخل بيانات حقيقية. ولا تُنفَّذ أي مدفوعات ولا تُحفظ أي سجلات طلاب فعلية.

## What is in this repository

- `index.html` — language gateway (Arabic / English)
- `ar/` — the Arabic website pages, right-to-left
- `en/` — the English website pages
- `css/style.css` — one stylesheet, with light and dark mode
- `favicon.svg` — site icon
- `.nojekyll` — tells GitHub Pages to serve the files as they are

The production server (payments, certificate issuing, teacher admin page and the
student database) is **not** part of this repository and is not published anywhere.

---

## Accessibility

Built with semantic HTML, a skip link on every page, visible focus styles, ARIA
labels where they are needed, and native right-to-left support for Arabic. The
pages are meant to work with a keyboard and with screen readers, and colours meet
contrast requirements in both light and dark mode.
